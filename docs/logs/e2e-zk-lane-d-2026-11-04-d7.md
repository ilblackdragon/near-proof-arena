## 2. Two node shapes, PAD at any level, multi-instance SHA (priority 1)

Code (`nv/tree.rs`, `nv/verifier.rs`, `nv/builder.rs`, `nv/circuit.rs`, `nv/hash.rs`; driver
`tree.rs`):
* `build_node2` (`P_2`): `force_anchor` on every child (level 1, template set, no BIND);
  `build_node_star` (`P_*`): anchor set `{C_2, C_padN}` at level 2, BIND for child 0 above, later
  children `root_i ∈ {root_0, C_padN}` (`Builder::sibling_alt`: boolean `p_i`,
  `flag·(1 − p_i)·(root_i − root_0) = 0`, `p_i·(root_i − C_padN) = 0`); `build_pad_node` (`PAD_N`,
  witness level). Without `sibling_alt` the D-5/D-6 programs are unchanged.
* `NvCircuit::sha_instances` up to 4: instance `i ≥ 1` is appended after the byte AIR, has its own
  lookback bus and `cid_offset = i·2^22`, shares the control/K table and the interface bus;
  `generate2_multi` fills instances in order; `shape_pinned_heights` spreads the SHA slack in fill
  order. A one-instance circuit is byte-identical to D-6 (AIR order, buses, vks).
* Structural last-used-row check (`used_rows_checked`, review-D5): every NvAir row below the last
  used one has exactly one role flag; every SHA row below it is real and the count is whole
  compressions.
* Driver: leaf geometry (NvAir 2^19, program 2^18), node geometry from `P_2`'s sizes (smallest
  NvAir / program / SHA-instance count holding them × the margin: 1.10 at depth ≥ 2, 1.0 at depth
  1), `h_N` = `P_2`'s pin × margin, checked against every node's shape pin before it is proved.
  `NEARPROOF_TREE_REUSE_LEAVES` (re-checked leaf reuse across arities, a measurement aid).

Runs (`run_d7.sh`, 8 threads on CPUs 8–15): see README §0 tables. Arity 2, depth 3, on h10006-s3
(class A, creates the setup) and h10027-s0 (class B, fixed setup): 7 tree proofs + wrap each.

Constraint level (`tree_d7_shapes_debug`, Fib fixture, 2 threads, 3,592 s, `results/zk/d7/test-d7.txt`):
honest base leaf / re-implemented base leaf / `P_2` / `P_*`@3 / `P_*`@4 (BIND + PAD_N sibling) /
wrap over the level-4 root pass; rejected: exposed ctx limb ≠ captured digest; captured digest

set; a wrong PAD alternative at level 4; `PAD_N` as child 0 at level 4. The 6 non-ignored
