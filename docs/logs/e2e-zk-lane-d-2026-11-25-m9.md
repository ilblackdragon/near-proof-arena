## What M9 changes

1. **No stub template.** Leaves: INIT (lane G G-4, main slot in-circuit) · STATE_IF (lane B B-T1) ·
   RT_ENTER (lane F F-2) · WASM seg 0, seg 1 (lane A A-T2, pinned tight heights: one leaf program)
   · RT_RESUME (lane F F-2) · STATE_SEG (lane B B-T1) · FINAL (lane G G-3). This is lane I's T1
   chain (`Templates.lean`). M9b inserts lane A's PREP (A-T3) before seg 0 (see below).
   Every child proof is the lane's own saved proof, verified natively by `m8-import`. Lane F's
   leaves were already on lane D's base configuration and in the `SavedVk` envelope, so nothing
   was re-proved.
2. **Boundary record = named regions** (`m9_spec.py`). Each leaf writes the regions its child
   exposes and passes the rest through. A value no real leaf produces before its consumer is a
   private witness of INIT ("free"). A value no real leaf consumes is read by FINAL into private
   witness cells ("dropped"). `spec.json` `edges` lists every edge.
3. **Circuit (adopted soundness / interface fixes, lane E M11i).**
   * **Phase codes.** The leaf-boundary phase is the `View.split` code: init 0, eng 1, fin 2,
     gfin 3, done 4, doneG 5, call 6 (`tree.rs` `PHASE_INIT = 0`, `PHASE_DONE = 4`,
     `PHASE_DONE_G = 5`; `htree.rs` `PHASE_MIDS = [1, 2, 3, 6]`). The wrap requires
     `s_a.phase = 0` and `s_e.phase ∈ {4, 5}`. PAD / PAD_N require `{4, 5}`. `TemplateSpec::check`
     refuses an input phase of 4 / 5 (review-D7 I3) and any unknown code. T1's templates: INIT 0→1,
     STATE 1→1, RT_ENTER 1→6, PREP / WASM 6→6, RT_RESUME 6→1, FINAL 1→4. The D-5..M8
     placeholders were 1 / 2 (and MID 3).
   * **`TailCanon` (range-digest tail).** In 42-byte mode GLUE sends word 5 limb 2 as `s5 − lo6`
     and range-checks only `4·lo6`. `hash_range`'s consumers did not pin the limb. The fix is in
     the program, not the AIR: `agg::pin_range_tail` rebuilds the high `Dig` cell as
     `pack(l12..l16, 64·t)` with `t = Σ_{i<16} 2^i β_i` (`LoadBit` cells), so limb 17 is
     canonical. The same pin is applied to `htree::limbs_of` (the 18 limbs of `h(B)` and of the
     child's cached commitments). About 50 extra rows per digest. No AIR or vk change: D0a's
     programs change (every node's `hash_range`), so the D-9 production setup is not reproduced
     by `pq-e2e-m9`. D-9's packets stay valid under their own deps tree `pq-e2e-d9`.
4. **Driver.**
   * `M8_REUSE` now requires the reused proof's program root to be the root this run generates
     (leaves: a trace generation; `P_2` / `PAD_N`: the computed `c_node2` / `c_pad_node`; `P_*`: a
     generation). Before, a stale leaf whose child changed but whose statement did not (lane A's
     re-proved segments, lane G's re-proved INIT) would have been reused. In the M9 run the G-3
     INIT leaf was correctly refused (`M8_REUSE LEAF0.proof NOT reusable`) and leaves 1..7 were
     reused.
   * A tree whose leaves fill every slot proves no PAD_L, but PAD_L's program is still generated
     for the template set. The first M9 attempt died on this (`a PAD_L program`).
   * `M9_SWAP_STUB=i,..` (`run_m9.sh swap`): leaf `i` is replaced by a statement-only stub that
     exposes exactly leaf `i`'s statement. The stub is proved at the leaf geometry, and `P_2` over
     its group with the run's template set must fail to generate.
   * The `RESULT.json` scope is taken from the spec.

## Edges: real vs prototype (M9 tree)

| edge | bound on both sides (real public values / commitments) | prototype (free / dropped) |
|---|---|---|
| INIT → STATE_IF | `prev_state_root`: INIT pv 28..44 = WSB pv 0..15 (the PSR join) | `ctxRoot` (INIT pv 14..28) carried, no consumer |
| STATE_IF → RT_ENTER | — | RT_ENTER `B_in` (408 B eng record) free: no leaf exposes `BndRec` of `eng I c` |
| RT_ENTER → WASM 0 (M9) / → PREP (M9b) | — | lane A's entry state free (`.pre → .ent`). M9b: the `.pre` record's Wasm part is free except `codeRoot` (= PREP's hash ‖ 0^10) |
| PREP → WASM 0 (M9b) | CODE / FUNC roots: PREP's cached commitments = seg 0's (R1 in-tree) | entry pc / ctx / mem (49 cells) free |
| WASM 0 → WASM 1 | lane A's boundary fields + CODE / FUNC roots | — |
| RT_ENTER → (WASM*) → RT_RESUME | **lane E `BndRec.encode` bytes** of the call record, 400 of the 408 non-Wasm bytes, carried unchanged across the Wasm leaves | `t` (8 B: lane A's clock is a field element, the record is 8 BE bytes); resume's `B_in` Wasm part (376 B, lane A's `fin r`) free |
| WASM 1 → RT_RESUME | (the carried call record above) | lane A's final state dropped |
| RT_RESUME → STATE_SEG | — | resume `B_out` (eng record), RX env / totals (247), TAPE / XTAPE roots dropped |
| STATE_IF … STATE_SEG | lane B chain: prev root, wsLen, `R_0 = R_in`; FINAL's leaf reads the last `R_out` and IF's `R_n` from one cell | — |
| STATE_SEG → FINAL | — | `finInDigest` (FINAL pv 14..28) free (FinIn is not opened by lane B; `FINB` = joint leaf) |
| `ctx` | INIT and FINAL: pv 0..14 = `claimDigest = bdigest(S)` (`CtxMode::Src`); V_d from `S` | rt leaves' `claimDigest` bytes are not tied to `ctx` (byte vs 3-byte-limb form; equal on T1, checked natively) |
| FINAL `B_out` | — | pv 28..58 (n, L, `ctxD(.header H)`, `outD(.done o).1`) pinned as T1 constants of the FINAL leaf program (the tree's DONE state carries no record) |

`BndRec` digests are used nowhere as the tree's record. No two adjacent leaves expose the same
`BndRec`: only lane F's leaves expose `BndRec.encode` bytes, and they are not adjacent. The
nearest real use is the carried call-record bytes between RT_ENTER and RT_RESUME.

## Findings

* **F-M9-1 (lane F).** Lane F's prover gives each AIR as many public values as its constraints
  read. ENT reads only `B_in` and the first 408 bytes of `B_out`, so the enter proof carries 816
  public values, not 1,192: `B_out`'s Wasm part (376 B, "out free" in `BndLay`) is not in the
  proof. Lane F's `d_out` (the plan's digest of the full 784-byte record) is therefore not a
  function of the proof. This is harmless for M9, where that part is free either way. But a leaf
  that hashes the enter record must get the Wasm part from PREP / lane A, not from ENT.
* **F-M9-2 (memory).** A node proof (`P_2` / `PAD_N` / `P_*` at NvAir 2^21, two SHA instances of
  2^22) peaks at **32.3 GB** in-process with streamed commitments (`NEARPROOF_STREAM_COMMIT=1`):
  the GKR transient. The 20G budget cannot hold it. The first M9 attempt was OOM-killed at the
  24G cap at the first `P_2`. The measured run used the coordinator's 34G allowance: process peak
  34.0 GB. Leaves peak at ≤ 14.6 GB.
* **Cross-setup negatives** (`m9_negatives.py`): the M8 stub-tree packet (same `S`) under the M9
  setup is rejected, and so is the M9 packet under the M8 setup. Both are rejected first by the
  pinned wrap heights, which differ (379,708 vs 379,944).

## M9b: PREP

PREP (lane A A-T3, `e2e-laneA/at3/prep/leaf`, 469,779 B) sits between RT_ENTER and seg 0, phase
call → call. Region `Wpre` (376 B) is the `.pre` record's `WasmBnd` bytes. PREP's 32 public hash
bytes plus 10 zero cells are its `codeRoot` cells (offset 292: `preCodeRoot = SHA-256(code) ‖
0^10`), the same on both sides. The rest of `Wpre` is free at INIT (RT_ENTER's proof does not
carry the Wasm part, F-M9-1) and is dropped at FINAL. PREP's cached CODE / FUNC commitments are
the W part's roots on its output. W's root cells are 0 before PREP, so seg 0's CODE / FUNC roots
are bound to PREP's in-circuit (R1 inside the tree). PREP's length (pv 32) is region `PLEN`
(carried, dropped). The leaf program root is `768878963b4ca981…` and the WASM program root is
`586d63e9e5579b39…`.
