## 1. `NvFaithful` for the node and wrap

**What was found first: the composition obligation was false.** `NvCompositionAt` (sub-obligation
6) was `ShaAt → TrAt → ProgAt → ArithAt → LogUpAt → accepts`, with no `HoldsLogUp`. Each `…At` is
an implication out of `HoldsLogUp`. So at a trace that does not satisfy the AIR, all five hold
vacuously, and the obligation demanded acceptance anyway (`nvCompositionOld_forces`). Any verifier
that rejects the decode of some non-satisfying trace refutes it (`nvCompositionOld_false`); the
aggregation node is one, since it rejects non-chaining children. `nvFaithful_of_obligations`
therefore had an unsatisfiable hypothesis, and "6 sub-obligations imply NvFaithful" was vacuous.
**Fix (adopted as a soundness fix):** the premise `HoldsLogUp Pin.air pub tr` is added to
`NvCompositionAt`. The proof of `nvFaithful_of_obligations` now passes `h`; its statement is
unchanged.

A second caution, recorded in the file header: the generic obligations' semantic parameters
(`digestOf`, `limbsOK`, `circuitSample`, `arithOK`, …) are free. So obligations 1, 2 and 4 are
trivially satisfiable by degenerate choices, and they only mean something at parameters tied to a
program.

**Transcription of `build_agg`** (`openvm-recursion-agg.patch`, `agg.rs`):
* `NodeKey`: `k ≥ 2` (the build-time `assert!`), `n_ctx`, `n_state`, and the child kind.
* `NodeRead`: the program's cells, as `Fin`-indexed functions, so every vector has its fixed
  length.
* `ContAsserts`: the continuity loop, with `zipEq` the Rust `zip`.
* `outCell`: `out = (f.ctx, f.a, l.e, f.s_a, l.s_e)`.

**Proved:**
* `zipEq_eq`: equal-length `zip` equality is equality.
* `zipEq_short`: without equal lengths the `zip` loop accepts a strict prefix, so the fixed shape
  is load-bearing.
* `compose_of_asserts`: on shaped cells the asserts make `compose (cells.map stmt) = some (stmt
  out)`.
* `node_composition`: **sub-obligation 6 for the node.** `NodeSha` (tag-9 jobs are the native
  digest), `NodeInner` (each `build_verifier` gadget = native acceptance of the child), `NodeTape`
  (the public digest is the `pv_digest` cells) and `NodeAsserts` (the per-kind statement link and
  continuity) imply that `aggNodeV` accepts. `AccNative` states what native child acceptance
  contains (verification plus `check_range_statement` or `of_segment`).
* `nvComposition_node`: the same in the generic `NvCompositionAt` slots, with SHA in `limbsOK`, the
  tape through an injective `encD`, and the asserts and inner verifiers in `arithOK`.
* `nvFaithful_node`: `NodeExec → NvFaithful Pin (nodeDecode …) (aggNodeV Acc rdigest)`.
* The wrap: `WrapRead`, `WrapComp`, `wrap_composition`, `nvFaithful_wrap`. They are stated
  against plan §3.4, because the wrap is not built yet.

**Open, with the reason.** `NodeExec`/`WrapExec`: on every trace satisfying the pinned NvAir with
the LogUp balance, the cells satisfy the four components. These are generic NV sub-obligations
1–4 at this program:
* 1: the SHA tables compute SHA-384;
* 2 + 4: the in-circuit verifier is the native one, recursively, including program binding of
  node children;
* 3: tape and program binding;
* 4: the assert rows hold.

They are premises about an opaque `HoldsLogUp Pin.air`, because no Lean NvAir value exists (no
exporter for `crates/recursion/src/nv/*`). They are neither provable nor refutable here.

`agg.rs`'s header says program binding of NV children "is not emitted by this node". The code sets
`b.bind_child = true` for node children, so the comment looks stale. `NodeInner` must include
`BIND`.

## 2. `LeafHolds` and `RangeBinding`

* `circSeg S0 segAir segStmt` is the circuit's segment system. Its `Holds k b b' (pub, tr)` is
  `ZkFormal.Air.Holds (segAir k) pub tr` (natural balance, the form the segment lanes prove), with
  `segStmt pub` having boundaries `b, b'`.
  `leafHolds_circ`: `LeafHolds A` for every `A : AggNode (circSeg …)` with matching
  `segAir`/`segStmt`, via `holds_of_holdsLogUp`. Obligation 2 over `circSeg` is exactly the
  segment lanes' per-template soundness.
* `rmsg encB` is the pinned `range_values` layout, `[n_ctx, n_state, ctx.., a, e, s_a.., s_e..]`.
  `rmsg_inj` shows it is injective for any injective `encB`; the two length prefixes make it
  self-delimiting, so no fixed-width assumption is needed.
  `rangeBinding_of`: if `rdigest = H ∘ rmsg` and an `H` collision is `rangeColl`, then
  `RangeBinding` holds.
  `hColl_bdigest`: for `H = bdigest ∘ ser` with `ser` injective, an `H` collision is a 42-B
  SHA-384 collision.
* Index wrap-around (`e = a + 1` in the field) does not matter for E2E soundness: `Leaves` uses only
  the boundaries.
* `e2e_sound_of_exec` assembles everything: `E2EStmt s ∨ BE.Any` from `NodeExec`, `WrapExec`,
  `ExtractWG`/`ExtractW`, `AccNative`, the decodes, `H`-CR and obligations 1b, 2 and 4.

## 3. The honest call tape (sub-agent, commit `037ed8332`)

* `TLe x y` relates a computation to its tape-indexed copy. If `x` succeeds, a tape `K` exists such
  that every `KOk` extension of `K` gives the same result. The `tape_walk` tactic mirrors
  `mono_walk`, and `pwO_tle` holds through every `CutW` layer and `stepMO`.
* `estepO_complete`.
* `honestK P c = (honestQ P c).map (q ↦ (q, callResult q))`, with `honestQ` chosen classically
  from `estepO_complete`.
* `estepO_honest : estepO (strictO (honestK P c)) P c = .ok c' ↔ estep P c = .ok c'`.
* `rsteps_honest`: `RCM` goes `base (eng I c) → base (eng I c')` through the honest calls, or by a
  base step if there are none.
* Engineering: unfolding `actionLoopW`/`drainW`/`stepMO` needs
  `simp (config := { zeta := false })`; otherwise join points are inlined and `split` runs out of
  steps.
* Open: a constructive recorder for `honestQ`.
