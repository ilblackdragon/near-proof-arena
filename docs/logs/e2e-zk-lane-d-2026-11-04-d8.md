## 3. Leaf cost (priority 3)

* `base-whir VK CERTS EXCL NS:LB[:W]… | seg:NS[:W]` (new driver command): the base WHIR schedule
  and soundness for the same AIRs at another geometry, the stack's own calibration
  (`results/zk/d8/base-whir.txt`). Σ queries × Merkle depth (the leaf's in-circuit hashing): D0a
  class A (ns18 lb7) 3,055; a 2^22-row segment at lb 1: **seg-v1 (lanes' parameters) 21,789**,
  base configuration 5,192 (32 grinding bits) / 5,366 (24 bits); class L (ns22 lb2) 4,804. Under
  seg-v1 the grinding bits barely matter (24 → 32: −3.5 %); the difference is the first-order
  certificates + list decoding m = 64.
* Levers considered: (a) the segment's WHIR parameters (the largest: ≈ 4×; lanes A/B's choice,
  recorded in plan §5.0.1 (4)); (b) **the leaf proof's own rate** (implemented); (c) a leaf over
  several segments (saves only the `P_2` level: ≈ 1 node per 4 segments; not built — the GPU
  model has no per-proof fixed cost to amortise); (d) in-circuit Merkle multiproof dedup (rejected:
  which paths share nodes depends on the query indices, so the leaf program would depend on the
  witness, breaking the class template); (e) a Merkle cap (data-independent, ≈ 30 % of Merkle
  hashing at 600 queries; needs a PCS + proof-format change; not built).
* **Implemented: `NEARPROOF_TREE_LEAF_PARAMS`** (D-8 default `ns20lb2`; `TreeShape.leaf_params`,
  setup version 5): template leaves and `PAD_L` are proved by their own engine; their program
  roots are committed under the leaf parameters; `P_2` reads the child parameters from its vk.
  Measured at equal threads (`leaf_ab_d8.sh`, the D-7 class-A base, 2 threads): 967 s / 13.2 GB at
  lb 5 → 588 s / 8.0 GB at lb 2 (proof 366 → 443 KB); `P_2` over lb-2 leaves at arity 4: pin
  +26 % NvAir / +25 % SHA over D-7's, 779–854 s vs 699 s; still 2^21 / 2 instances.
* Segment-geometry leaf measured (class L base: `n_stack` 22, lb 2): 465,618 program rows, NvAir
  812,648, SHA 1,750,912 (1 instance), 210 M cells, 141 s / 13.5 GB on 8 threads.
* Projection (`tree_d8_model.py`, model only): see README §0; 1 Pgas 21.2 → 14.2 s, 100 Tgas
