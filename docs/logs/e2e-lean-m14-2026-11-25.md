## 2. The tag (`StateView.posTag`) and the soundness argument

`tagOf (.eng p _) = posTag p`: `start` 1, `done` 3 (both as in B-T2), `txs` 4, `locals` 5, `delayed`
6, `incoming` 7, **`yields _ _ 0` 8** (the finalize precondition `GlueFin.FinPre`), other `yields` 9;
`none` 0, `fin` 2. Lean (lane B's files, rebuilt; lane E's `join/RestI.lean`):

* **Binding is unchanged**: `tagOf` is a function of `v`, `≤ 9 < 255` (`tagOf_le`, so `ser_ne_raw`
  holds), and `proj_inj` takes tag equality as a hypothesis; `stD_binding_BI` (`Sha384Coll ∨
  Sha256Coll ∨ LeafColl`) is the same theorem. The tag adds no information: it is a function of the
  moving part (`tagOf_restMove`: `tagOf (restMove (restOfB v)).1 = tagOf v`).

  `stD P v` with tag `< 255` is `commitOf P v`, or a collision), `tag_eq`, and on the view's
  `stOfI`: `finPos_of_tag` (tag 8 ⇒ `c.pos = yields _ _ 0 _ _ _`), `incoming_of_tag` (7),
  `done_of_tag` (3); `posTag_eq3/4/5/7/8`, `tagOf_stOfI`.
* Lane B's `StHalfC`: `StPosOK` = an opening with `NonFinTag t` (`t = 1 ∨ 4 ≤ t ≤ 9`);
