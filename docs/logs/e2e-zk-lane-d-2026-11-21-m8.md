## What was built

1. **Generic template leaf** (`nv/htree.rs`): `TemplateSpec` (phases, input / output boundary
   record cells from child public values, cached-commitment limbs, statement cells, pass-through
   witnesses or constants; `ctx` source; public-value equality groups and pins), `check` (complete
   binding of every public value and cached commitment; no DONE input), `build_tmpl_leaf`
   (verifies the child with its vk and heights as constants, binds the record, exposes
   `H9(ctx, a, a+1, [phase, h(B_in)], [phase, h(B_out)])`). `tree.rs`: PAD / nodes / wrap accept
   any boundary-state width (D0a programs unchanged: width 2). `verifier.rs`: an aggregation-mode
   caller receives the child's cached commitment cells.
2. **Driver** (`pq-chunk-e2e/src/htree.rs`): `m8-prove-a` (lane A segment dump → proof under the
   verifier's backend at the stack's base configuration; lane A's `air.rs` and `s384/` read-only
   via `#[path]`), `m8-prove-b` (lane B M5b dump → proof; pq-state-port interpreter with `maxLog`
   caps, classical SHA-256 generator, TAPE / HTAPE harness tables as lane B builds them),
   `m8-tree` (leaves, one leaf geometry, `P_2` / `PAD_N` / `P_*`, wrap), `m8-verify`.
3. **`ctx` = `claimDigest`** (integrator, 2026-11-21): the packet is `S ‖ wrap proof` with `S` the
   canonical statement bytes of plan §3.4.1; V_d computes `ctx = limbs(bdigest(S))`. T1:
   `|S| = 1,007 B`, `claimDigest = bb5aad11…9f2f01` (checked by `m8_spec.py` against lane E's
   kernel value).
4. **Depth-0 D0a tree** (item 4, code only): `tree-prove … DEPTH 0` with one leaf family: the
   wrap verifies the template leaf directly (no `P_2`, no `PAD_L`).

  the wrap (FINAL geometry not exported by the script; fixed), not resumed (older `ctx` form).
* **Findings:** lane A's template leaves two tight heights unpinned (CODE, SHA-512 chip: two leaf
  programs); `PAD_N` costs a full node (~800 s); lane G's INIT / FINAL and lane F's `rt` proofs are
  not saved on the stack backend yet.

  starvation in the first run; the lane's session stalled once (stream watchdog) and was resumed
