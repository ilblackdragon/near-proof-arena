# Zero-knowledge argument for the chunk proof: construction, simulator, hiding error, cost

Status (2026-11-03, lane E2E-D, milestone D-3). **The FINAL layer now runs `zk = 6`. Every
lemma of the simulator argument is proved in §6, for the statement *(claim, setup, trace
heights)*.** The concrete hiding error is **ε_ZK ≤ 2^-184.4** (§6.4). `zero_knowledge_established`
still stays `false`, for one reason that is not a lemma of the simulator. The per-AIR trace
heights are sent in the clear, and nothing yet shows that they are a function of the claim and
the setup (independent review, finding #4; §7, obligation H).

The D-2 version (`zk = 5`, in git history) left two lemmas open:
* **Lemma D:** the joint `F`-rank of the extension-field functionals of the base-field stacking
  mask columns.
* **Lemma E:** joint absorption, per column, of the opened rows and the stacked opening `q_k(u)`.

Both came from base-field cells absorbing extension-field functionals. D-3 removes both causes:
* **No stacked opening is sent.** WHIR batches the columns with `μ^j + ν·c_j`, where `c_j` are the
  stacking reduction's final coefficients. The prover sends one value `B` after `μ`, and `ν` is
  sampled after `B` (§3.2, §5). Lemma E becomes exact Vandermonde absorption (Lemma V).
* **The stacking masks `M_1`, `M_2` are extension-field columns.** Each is
  `Σ_b e_b · col_b` over 12 base columns. Lemma D is then over `EF`, where Schwartz–Zippel applies
  (Lemmas D1, D2).

Mode: `WhirLevers::zk = 6` on the FINAL layer (`NEARPROOF_ZK_FINAL=6`). It is `zk = 5` (the PCS
layer, the split packing and the PIOP masks of §4) plus the two changes above. The base layer
stays `zk = 1`, and the inner NV levels stay `zk = 0`. Patches:
`native/recursion/patches/{e2e-verify,zk-pcs,zk-piop}.patch`; `zk-piop.patch` is regenerated by
`make_zk_piop_patch.sh` and now also carries the D-3 code. Shared definitions are in
`stark-backend/src/zk.rs`.

## 1. What must be hidden, level by level

Only the packet is published: `claim.bin` (the statement), the hint (derived outputs, checked
against the claim), the base point `u`, and the FINAL proof. The setup is trusted and public.

| level | published? | must hide | why |
|---|---|---|---|
| base | only `u` (and `y = T_pub(u)`, which the verifier computes) | `u` must be simulatable | `u` is the RO output of the base transcript. Without randomness in the base commitment, `u` is a deterministic function of the witness, so anyone could test a guessed witness. |
| L1 … L_n | no | nothing | each is only the witness of the next level; the FINAL proof's ZK covers it |
| FINAL | yes | everything except its public values (level, statement digest), the shape (trace heights, §7), and the pinned program | its trace is the NV verifier run on L_n, so leaking the trace leaks L_n and hence the chain |

ZK at an inner level would not work. A ZK simulator programs the random oracle, but the next
level recomputes that oracle (SHA-384) inside its circuit. FINAL is the one proof whose
transcript is evaluated only natively, under its own transcript domain
(`ShaTranscript::new_layer(true)`). Programming the oracle at FINAL's points is therefore
consistent with every in-circuit evaluation. The recursion circuit is unchanged. The NV generator
now asserts that a child proof is never masked (review #7).

Public columns. The NvAir program columns `P0..P3` hold the pinned program, and V_d checks
their openings against it (`vd::check_final_program_at`). Their content is public, so their
plain openings are sent unmasked (`StarkVerifyingParams::zk_public_cols`). V_d now takes the
batch point `r` from `verifier::verify_with_point`, not from a thread-local (review #6). Its
replay path rejects masked proofs explicitly.

## 3. PCS layer

### 3.1 Commitment layout

* Every stacked data column keeps its last `R = 256` rows free (`ZK_RESERVE_ROWS`). Packing is
  first-fit decreasing with slice splitting (`StackedLayout::new_tight_zk`; the halves fill only
  existing gaps). The prover fills the free rows with fresh uniform elements, by rejection
  sampling of `/dev/urandom` (`zk_fill`). No trace slice lies there, so no PIOP claim weighs them.
* `zk = 6` appends **37 mask columns**, all filled uniformly, in this order:
  * `P_0..P_11`: 12 pure pad columns. They appear only in WHIR's batched polynomial, with
    coefficients `μ^{j_0}, …, μ^{j_0+11}`; their stacking coefficients are 0.
  * `M_2`, `M_1`: two extension-field columns of `D = [EF : F] = 12` base columns each.
    `M_j = Σ_b e_b · col_{m_j + b}`, where `e_b` is the basis of `BasedVectorSpace`
    (`zk::mask_columns_ef`, `zk::ef_column`).
  * `M_s`: one base column. Its rows `16k .. 16k + 11` store the extension-field mask
    coefficient `k` of §4. Coefficients must stay below the top `R` rows: the verifier rejects
    `16·coef_end > 2^21 − 256`, and the prover asserts it (review #5).
* For FINAL that is 53 data columns plus 37, so **90 stacked columns** (`zk = 5`: 68).
* **Packing termination (review #1, fixed).** A slice that fits no column and has larger slices
  behind it is re-queued behind the *last* strictly larger slice, and the loop is bounded
  (`ZkLayoutNoProgress`). The old rule inserted it at the first slice of size ≤ its own. With a
  declared tight height of `2^(l_skip + n_stack)` that put a half in front of its twin, and the
  same state repeated forever: a verifier hang on a prover-chosen height. In every run that
  terminated the queue was sorted at that point, and there both rules give the same position.
  So no honest layout changes: the 68/1,536 and 90/1,536 layouts are regression tests
  (`stark-backend/tests/zk_layout.rs`).
* **No-layout heights are errors (review #2, fixed).** `verify_proof_shape` maps a layout error
  to `StackingProofShapeError::NoLayout` instead of `unwrap()`. This covers zk 1/2/4 with a
  full-height chunk, which also reaches the base layer. That case is a completeness gap: those
  modes cannot commit a trace that fills the stacked height. The FINAL layer uses splitting, so
  it is not affected.

### 3.2 Batching (`zk = 6`): no stacked opening

The stacking reduction ends with the identity `S = Σ_j c_j·q̂_j(u)`. Here `S = s_n(u_n)` is the
last round's value, `c_j` are the coefficients the verifier computes from `(λ, r, u, τ_1, τ_2,
sparse weights)`, and `q̂_j` is the multilinear extension of stacked column `j`
(`verifier::stacked_reduction::stacking_final_coeffs`, shared by prover and verifier). Upstream
and in `zk ≤ 5`, the prover sends every `q̂_j(u)`, and the verifier checks the identity and
batches `g = Σ μ^j col_j` with claim `Σ μ^j q̂_j(u)`. With `zk = 6`:

1. The verifier does not check the identity. It returns `(S, c)`
   (`StackedReductionOut::deferred`).
2. In WHIR, after the `μ` PoW and `μ`, the prover sends `B = Σ_j μ^j q̂_j(u)`
   (`stacking_proof.zk[2]`, observed). Then `ν` is sampled.
3. WHIR runs on `g = Σ_j (μ^j + ν c_j)·col_j` with initial claim `ĝ(u) = B + ν S`
   (`WhirBatch::Deferred`). The verifier computes `g`'s initial-round coset values from the
   opened rows with the same coefficients.

The cost is one EF element (48 B) in place of the 68 stacked openings (3,264 B) that `zk = 5`
sends. The 22 extra base columns of `M_1`, `M_2` cost `22 × 4 B × 2 × 46` ≈ 8.1 KB of opened
rows (§8).

### 3.3 Opened initial rows

Each query reveals every stacked column's codeword symbols at its coset: two points, `±x`, with
`k_first = 1`. That is `s ≤ 2·46 = 92` symbols per column at 268 bits, and 94 at 274 bits.
The codeword of a column `v` is `Σ_i (Tv)_i·α^i`, where `T = eval_to_coeff_rs_message` is
block-diagonal with invertible 4×4 blocks (a skip-domain iDFT and a 2-variable Möbius
transform). The top `R` rows form 64 whole blocks. What absorbs the symbols is Lemma V (data
columns and `M_s`) and Lemma D1 (`M_1`, `M_2`). The pad symbols are determined by `g` and the
other columns.

### 3.4 Base point `u`

With `zk = 1` the base root is an RO hash of leaves that carry fresh randomness. So `u`, which
is squeezed after the root, is uniform and independent of the witness except with probability
`q · 2^{-336}`. The simulator samples `u` uniformly and computes `y = T_pub(u)` and the
statement digest itself.

## 4. PIOP masking (`zk >= 4`; stacking masks extension-field valued for `zk = 6`)

Every GKR and batch mask is an extension-field coefficient. It is stored in `D = 12` base cells
of `M_s`, at rows `16k .. 16k + 11` for coefficient `k` (`zk::MaskCoefs`), and it is uniform
because `zk_fill` fills `M_s` uniformly. The masks are fixed by the commitment, that is, before
every challenge. Each masked sumcheck ends in a **sparse claim** `Σ_i w_i · coef[c_i] = V`.
The verifier derives `V` from the sumcheck's final check; `V` is never sent. The stacking
reduction proves all sparse claims together with the column-opening claims. Coefficient
allocation is deterministic from the shape (`GkrZkLayout`, `BatchZkLayout`). FINAL uses about
1,700 coefficients, which is about 27 K rows of `M_s`'s 2 M.

### 4.1 Masked GKR (`verify_gkr_zk`, `fast::gkr::fractional_sumcheck_fast_zk`)

LogUp GKR over `K = l_skip + n_logup` levels (`K = 27` for FINAL). Level `k` has `2^k` nodes,
with `p_k(b, y)` and `q_k(b, y)` where `b` is the newest coordinate. The layer relation is
`p_k = p_{k+1}(0,·)q_{k+1}(1,·) + p_{k+1}(1,·)q_{k+1}(0,·)` and `q_k = q_{k+1}(0,·)q_{k+1}(1,·)`.

* **Level masks** (off the cube, last coordinate): for `k ≥ 2`,
  `p̃_k(b, y) = p_k(b, y) + y_last(1 − y_last)·α^p_k(b)`, and likewise `q̃_k`. Here
  `α_k = (α^p(0), α^q(0), α^p(1), α^q(1))` are uniform coefficients. On the cube nothing
  changes, so every layer relation still holds. The claims the prover sends for level `k`, at
  `(b, ρ_{k-1})`, are masked by `Z_k α_k(b)` with `Z_k = ρ_last(1 − ρ_last) ≠ 0`. Level 1 is
  masked by `b(1 − b)·α_1`.
* **Root**, replacing the upstream `p_1(0..1), q_1(0..1), q_0` messages that leaked half sums
  and the product of all denominators: a one-variable sumcheck for
  `Σ_b p̃_1(b)·q̃_1(1 − b) = 0`, with Libra mask `g_R` (degree 4; the prover sends `G_R`, then
  `s_R(1..4)`). It ends in `P = p̃_1(β)` and `Q = q̃_1(1 − β)` at a fresh `β`. The upstream
  check `q_0 ≠ 0` is dropped. Some leaf denominator is zero, as a polynomial in the LogUp `α`,
  with probability at most `2^27/|EF| = 2^-343`, because the trace is committed before `α`.
  With all denominators non-zero, `p_0 = 0` ⟺ `Σ p/q = 0`.
* **Layer 1** (one variable `y`): the summand is
  `eq(β, y)[φ_p + M_1] + λ eq(1 − β, y) φ_q + ρ h_1(y)`, with claim `P + λQ + ρH_1`. `h_1` has
  degree 5, and the round has degree 5 (the prover sends `s(1..5)`).
* **Layer `k ≥ 2`**: the upstream Gruen sumcheck of `eq(ξ, y)[φ_λ + M_k + ρ h_k(y)]`, with claim
  `C_k + ρH_k`. `M_k = Z_k(α^p_k(μ) + λα^q_k(μ))` makes the identity hold for the masked
  claims. The Libra mask is `h_k = Σ_i h_{k,i}(y_i)`, with degree 2 per variable and 4 for the
  last one. All rounds except the last are unchanged in the prover: the mask of level `k+1`
  vanishes while `y_last` is Boolean. The last round has a quartic reduced polynomial (the
  prover sends `s(1..4)`) and is evaluated from the two remaining table entries.
* Each sumcheck's final check defines `V = s(r)/eq − φ(claims)`, the sparse claim
  `V = M + ρ h(r)`. The GKR output `p̃(ξ), q̃(ξ)` carries the input-level mask `M_K`, which the
  batch sumcheck absorbs.

Proof format (`GkrProof::zk`): `[G_R, s_R(1..4)]`, `[H_1, s(3..5)]`, and per layer `k ≥ 2`
`[H_k, s_last(3), s_last(4)]`. `claims_per_layer[0] = (P, Q)`, and no claim is derived. Cost
about 4 EF per layer.

### 4.2 Masked batch sumcheck (`verify_zerocheck_and_logup_zk`, `finish_zerocheck_and_logup_zk`)

* **No per-AIR LogUp terms.** Every AIR's numerator term is batched with coefficient 1 and its
  denominator term with `μ`; the zerocheck of AIR `t` uses `μ^{2+t}` and the mask `μ^{2+T}`.
  The claim is `p̃(ξ) + μ(q̃(ξ) − α) + μ^{2+T} G_b`. This is sound because the GKR needs only
  the sums.
* **Libra mask** `g(X, y) = h_0(X)·eq(ξ_y, y) + eq_D(ξ_0, X)·eq(ξ_y, y)·Σ_i h_i(y_i)` (`G_b`
  is sent before `μ`), plus the GKR input mask `eq_D·eq_y·M_K`. `h_0` has the full uni-skip
  degree 30, and every round keeps its `eq1(ξ_i, X)` factor, so Gruen still applies.
* **Column masks:** every column of AIR `t` is masked in the AIR's *last* multilinear variable:
  `f̂ = f + y_{n_t}(1 − y_{n_t})·A`, with one coefficient `A` per opening (plain and rotated).
  The uni-skip round and every round before `n_t` are unchanged. In round `n_t` the AIR's
  contribution has degree `2d`, and the prover evaluates it from its two-row tables. The other
  AIRs' degree-`d` part is extended by interpolation (`LogupZerocheckRowMajor::
  zk_masked_last_round`). That round sends `d` more evaluations (`BatchConstraintProof::zk`).
  Opening `t̂ = t + Z_t A` with `Z_t = r_{n_t}(1 − r_{n_t})`. Masking the uni-skip variable
  instead (`Z_D(X) = X^4 − 1`) would need extension-field masks inside the base-field round-0
  evaluator.
* Sparse claim `V_b` = the mask's value at the final point; each opening's mask enters the
  stacking claim of its column.

### 4.3 Masked stacking reduction (`verify_stacked_reduction_with`, `prove_stacked_opening_reduction_zk`)

* Before the batching challenge `λ`, two points `τ_1, τ_2 ∈ EF^{1+n}` are sampled (`n = n_stack =
  19`; coordinate 0 is the skip variable). The prover sends `G_j = M̂_j(τ_j)`.
* The claims are batched by powers of `λ`, in this order: the column openings with their mask
  terms, the sparse claims, then `G_1` and `G_2` (`λ_j = λ^{2T+n_V+j-1}`). The summand gains
  `E·M_s + λ_1 eq_prism(τ_1,·)·M_1 + λ_2 eq_prism(τ_2,·)·M_2`, where `E` collects the batched
  sparse weights on the coefficient cells.
* **`zk = 6`:** `M_1` and `M_2` are the extension-field columns of §3.1. The prover folds the
  `EF` tables `Σ_b e_b col_b`. The final coefficient of base column `m_j + b` is
  `λ_j eq_prism(τ_j, u)·e_b`. In `zk ≤ 5` they were single base columns, and that was the
  source of the old Lemma D.
* The mask's contribution, per round, is as follows:
  * **Round 0** (skip variable, degree 6): `Σ_j λ_j eq_D(τ_{j,0}, X)·R_{j,0}(X)`, where
    `R_{j,0}(X) = M̂_j(X, τ_{j,cube})` has degree ≤ 3.
  * **Round `i ≥ 1`** (degree 2): `Σ_j λ_j E_{j,i} eq1(τ_{j,i}, X)·R_{j,i}(X)`. Here
    `R_{j,i}(X) = M̂_j(u_0, …, u_{i-1}, X, τ_{j,>i})` is linear, and
    `E_{j,i} = eq_D(τ_{j,0}, u_0)·Π_{0<l<i} eq1(τ_{j,l}, u_l)`.
  * Its value at `X = τ_{j,i}` is `R_{j,i-1}(u_{i-1})`. That value is already fixed, so the
    fresh part of round `i` is `σ_{j,i}·eq1(τ_{j,i}, X)(X − τ_{j,i})`, where `σ_{j,i}` is the
    slope of `R_{j,i}`.

### 4.4 Soundness of the masked PIOP (unchanged from D-2)

No new commitment is added. Every mask is committed before every challenge, and every new check
is a polynomial identity of bounded degree. The per-round degrees are:
* GKR: up to 5 (the masked last rounds and the layer-1 round);
* batch: up to `2d + 1 = 19`;
* root: 4.

The new batching coefficients are:
* `ρ_*` (Libra, degree 1);
* `μ^{2+T}` (degree `T + 2`);
* the stacking `λ` powers over `K + 3` more claims.

`SoundnessCalculator` charges all of these when `zk >= 4`. The independent review (2026-11-03,
appendix A) re-checked this part and found no soundness break. The `zk = 6` batching is §5.

## 5. Soundness of the `zk = 6` batching (re-derived)

Notation:
* `W` is the number of stacked columns. The calculator uses the verifier-enforced bound
  `W ≤ w_stack = 4096`.
* `C` is the initial RS code: rate `2^-6`, degree `2^21`.
* `δ` is the initial proximity parameter.
* `J` is the joint list: tuples of codewords `(w_j)` that agree with the committed `(col_j)` on a
  common set of density ≥ `1 − δ`. It has `|J| ≤ ℓ_0` (the calculator's initial list size; the
  Johnson bound holds for the interleaved code).
* `E_k` is the MCA bad-set size for a degree-`k` curve, from the same theorem
  (BCHKS25 / DKT26 MCA) as every other WHIR move. The calculator computes `E_k/|F|` as
  `log2_err` with `batch_size = k + 1`.

**State before WHIR.** The stacking reduction's rounds are unchanged, with the same error terms
(the list factor `ℓ_0` included, as before). Its doomed state at the end is:

> **(D0)** for every `w ∈ J`: `Σ_j c_j ŵ_j(u) ≠ S`.

In `zk ≤ 5` the verifier checked `S = Σ_j c_j q_j` against the sent `q_j`, and WHIR's μ move then
paid `ℓ_0(W−1)/|F|` for the consistency of `q` with `J`. With `zk = 6` there are no `q_j`.

**Lemma 5.1 (μ move).** Fix the commitment. Except for `μ` in a set of density
`≤ E_{W−1}/|F|`, the following holds. For every set `S'` of density ≥ `1 − δ` on which
`f_μ = Σ_j μ^j col_j` agrees with a codeword `f`, every `col_j` agrees with a codeword `w_j` on
`S'`, and `f = Σ_j μ^j w_j`.

*Proof.* This is the MCA theorem for the degree-`(W−1)` curve `(col_0, …, col_{W−1})`. The
identity `f = Σ μ^j w_j` holds on `S'`, and `|S'| > deg C`, so it holds as codewords. □

The post-μ state is "(D0) and `μ` is good". Its flip probability is `E_{W−1}/|F|` (plus `μ`
PoW, 0 bits here). This is the calculator's unchanged `whir_mu` term.

**Lemma 5.2 (ν move).** Let `D = Σ_j c_j col_j`, so that `g = f_μ + ν D`. Suppose (D0) holds,
`μ` is good, and the prover has sent any `B`. Then
`Pr_ν[ some codeword f' δ-close to g has f̂'(u) = B + ν S ] ≤ E_1/|F| + ℓ_0/|F|`.

*Proof.*
1. **MCA of the line `(f_μ, D)`.** Except for `ν` in a set of density `≤ E_1/|F|`, every
   codeword `f'` that agrees with `g` on some `S'` of density ≥ `1 − δ` has the form `f + νe`,
   where `f` agrees with `f_μ` on `S'` and `e` agrees with `D` on `S'`.
2. By Lemma 5.1, `f = Σ_j μ^j w_j` with `w_j` agreeing with `col_j` on `S'`, so `w ∈ J`.
3. `Σ_j c_j w_j` and `e` both agree with `D` on `S'`, and `|S'| > deg C`. Hence
   `e = Σ_j c_j w_j`.
4. So `f̂'(u) − B − νS = (Σ_j μ^j ŵ_j(u) − B) + ν·(Σ_j c_j ŵ_j(u) − S)`. By (D0) the slope is
   non-zero, and `B` was fixed before `ν`. Each `w ∈ J` therefore allows at most one `ν`, which
   gives `ℓ_0/|F|` over `J`. □

After the ν move, the state is WHIR's usual initial doomed state ("no codeword in `g`'s list
satisfies the claim"). Every later WHIR move is unchanged. `μ` and `ν` are separate moves, so
round-by-round soundness holds with these two per-move errors. No error is moved between rounds
by an averaging (Markov) argument; that would have halved the bits.

**Terms in the form `docs/zk-formal/E2E-SOUNDNESS-BUDGET.md` §3.1 consumes** (FINAL layer,
`zk = 6`; ROM/QROM transfer as in that document: `ε_rbr` is per move, and the Q / Q² factors are
applied there):

| move | formula | FINAL value (268 / 274 target) | change vs `zk ≤ 5` |
|---|---|---:|---|
| μ batching (W ≤ w_stack) | `E_(W−1)/\|F\|` | 2^−283.6 / 2^−283.6 (calculator `whir_mu`) | drops `ℓ₀(W−1)/\|F\|` (no per-column claims) |
| **ν batching (new)** | `E_1/\|F\| + ℓ₀/\|F\|` | 2^−295.6 / 2^−295.6 (calculator `whir_nu`) | new move |
| stacking final check | deferred into the ν move | — | was an exact check against sent `q_j` |
| shift queries + PoW, OOD, fold, γ | unchanged | min 2^−268.2 / 2^−274.0 | — |
| masked PIOP (GKR deg 5, batch `2d+1`, `T+2`, `K+3` claims) | as D-2 §4.4 | ≥ 2^−321.9 | — |
| **FINAL `ε_rbr`** | max | **2^−268.2 / 2^−274.0** | unchanged |

The FINAL `ε_rbr` is still set by the WHIR query move. `zk = 6` adds no term near it.
`SoundnessCalculator::calculate_whir_soundness` charges the ν move under `levers.zk_batch()`
(`WhirSoundnessCalculator::nu_batching_bits`, printed as `whir_nu`).

## 6. Simulator and hiding error

The statement is `(claim, setup, heights)`. Here `heights` are the per-AIR log and tight
heights of the FINAL proof (§7). Fix `n = 19`, `N = 2^21`, `R = 256`, `|EF| = p^12 ≈ 2^370.9`,
and `s ≤ 94` opened symbols per column.

### 6.1 Simulator `S` (random-oracle model with programming)

`S` samples every challenge itself and programs `H` at the corresponding transcript prefix. It
aborts if `H` was already queried there.

1. **`u`**: uniform (§3.4). `S` computes `y = T_pub(u)` and the digest.
2. **GKR**: `G_R` and `s_R(1..4)` uniform (`s_R(0)` follows from the sum check); `P`, `Q`
   uniform; for every layer, `H_k`, every sent round evaluation, and the next level's four
   claims uniform.
3. **Batch**: `G_b` uniform; the uni-skip coefficients uniform subject to `Σ_D s_0 = claim`;
   round evaluations uniform (the Gruen-derived one computed); masked openings `t̂` uniform;
   public program openings computed from the pinned program at `r`.
4. **Stacking**: `(G_1, G_2, s_0, s_1, …, s_n)` uniform over the transcripts that pass the
   verifier's sum checks. `S := s_n(u_n)`.
5. **Opened rows**: for each query coset, the symbols of every data column, of `M_s`, and of the
   24 base columns of `M_1`, `M_2` uniform.
6. **WHIR**: `g` uniform in `EF^N`. `S` runs the honest WHIR prover on `g`, sets
   `B := ĝ(u) − ν S`, and solves the 12 pad symbols at each opened point from
   `g(α) = Σ_j γ_j sym_j(α)`. The pad coefficients `μ^{j_0..j_0+11}` form an `F`-basis.
7. **Merkle**: the opened leaves are hashed honestly; every unopened leaf digest is a uniform
   string. PoW witnesses are ground on the simulated transcript.

### 6.2 Lemmas

* **Lemma A (Libra masked sumcheck, with the eq factor).** Let `F` be any summand of individual
  degree ≤ `d_i`. Let the mask be `eq(ξ, y)·Σ_i h_i(y_i)`, with `h_i` uniform of degree `d_i`
  over `EF`, `ρ ≠ 0`, and every `eq1(ξ_i, x) ≠ 0` at the evaluation points. Then `H` and the
  round messages are uniform over the transcripts consistent with the verifier's sum checks,
  independently of `F`.
  *Proof.* Given the earlier messages, the non-constant coefficients of `h_i` enter only round
  `i`, as `ρ·A_i·eq1(ξ_i, X)·(h_i(X) − h_i(0))` with `A_i = Π_{j<i} eq1(ξ_j, r_j) ≠ 0`. That is a
  bijection onto the `d_i`-dimensional space of reduced round polynomials with a fixed sum. The
  constants together with `H` account for the remaining degree of freedom. This is CFS17 /
  Libra Thm 3. It is exact outside `ρ = 0` or `eq1 = 0`. Coverage: GKR layers, the root, the
  batch sumcheck, and the sums `H`, `G`. The final value fixes the hidden `V`.
* **Lemma B (level masks).** The level-`k` claims are `p_k(b, ρ) + Z_k α^p_k(b)` and similar, with
  `α_k` uniform over `EF^4` and `Z_k ≠ 0`. Elsewhere `α_k` appears only in the hidden `V_k`. So
  the claims are uniform. The root's `P`, `Q` work the same way, with `β(1 − β) ≠ 0`.
* **Lemma C (column masks).** `t̂ = t + Z_t A`, with `A` uniform over `EF` and `Z_t ≠ 0`. `A`
  appears elsewhere only in sparse weights. Exact.
* **Lemma V (Vandermonde absorption; replaces D-2's Lemmas S and E).** Let `v ∈ F^N` be a column
  whose top `R` cells are uniform and independent of everything else. For any distinct non-zero
  `α_1, …, α_s ∈ F` with `s ≤ R`, the symbols `(Σ_i (Tv)_i α_l^i)_l` are uniform in `F^s` and
  independent of `v`'s other cells.
  *Proof.* `T` is block-diagonal with invertible 4×4 blocks, and the top `R` rows are 64 whole
  blocks. So the symbols equal `(function of the other cells) + V_α·T_top·v_top`, where
  `V_α = diag(α_l^{N−R})·(α_l^t)_{l, t<R}`. `V_α` has rank `s`, as a Vandermonde matrix with
  distinct nodes times a non-singular diagonal. `T_top` is invertible. So the map is onto
  `F^s`. Exact. □
  It applies to every data column (the reserved rows) and to `M_s`, whose coefficient rows are
  below `N − R` (verifier check and prover assert, review #5). It also applies to `s + 2` points,
  which is used in §6.3.
* **Lemma D1 (extension-field mask column with its symbols).** Let `M ∈ EF^N` be uniform. Take
  the `n + 4` functionals:
  * `ρ_z(M) = M̂(z, τ_cube)` for `z ∈ D`;
  * `σ_i(M) = M̂(u_0, u_1, …, u_{i−1}, 1, τ_{i+1..n}) − M̂(u_0, …, u_{i−1}, 0, τ_{i+1..n})`
    for `i = 1..n`.

  Add the `s` symbol functionals `ψ_l(M) = Σ_i (TM)_i α_l^i` (distinct non-zero `α_l ∈ F`,
  `s ≤ R`). For uniform `τ_cube` and `u`, and any fixed `α`, the `n + 4 + s` functionals are
  `EF`-linearly independent except with probability `≤ (n² + 6n)/|EF| = 475/|EF|`. When they are
  independent, their values are uniform in `EF^{n+4+s}`.
  *Proof.* In the cell basis, write the minor on the columns `C' ∪ E'`:
  * `C'` = rows `0..3` (block 0) and the first row of block `2^{i−1}`, for `i = 1..n`;
  * `E'` ⊂ the top `R` rows, a set of `s` columns on which `ψ` has full rank (it exists by
    Lemma V).

  Every entry is a polynomial in `(τ_cube, u)`:
  * `ρ_z` is multilinear in `τ_cube`, of degree ≤ `n`;
  * `σ_i` is a product of `eq_D(u_0, ω^z)` (degree 3), multilinear eq factors in `u_{<i}`, and
    `τ_{>i}`, of degree ≤ `n + 2`.

  So the determinant has degree ≤ `4n + n(n+2)`. Specialize to `τ_cube = 0, u = 0`. Then
  `ρ_z = M(z, 0)` and `σ_i = ¼ Σ_{z∈D} (M(z, e_i) − M(z, 0))`, using
  `eq_D(0, z) = ¼` from `eq_D(x, y) = ¼(1 + x³y + x²y² + xy³)` (`l_skip = 2`). Both are
  supported on rows `< N/2 + 4 < N − R`, which do not meet the top block. The minor becomes
  block lower-triangular, `[[Φ_{C'}, 0], [Ψ_{C'}, Ψ_{E'}]]`:
  * `Φ_{C'}` is lower-triangular with diagonal `(1, 1, 1, 1, ¼, …, ¼)`;
  * `Ψ_{E'}` is non-singular.

  So the determinant polynomial is non-zero, and Schwartz–Zippel bounds the bad set. A full-rank
  EF-linear map of a uniform vector is uniform. □
  `ρ_z` and `σ_i` are exactly what the stacking transcript can depend on (§4.3).
  `G_j = R_{j,0}(τ_{j,0})` is in the span of the `ρ_z`.
* **Lemma D2 (the stacking transcript is a bijective image of the mask functionals).** Fix
  `(τ, u, λ)` outside a bad set of probability `≤ (21 + 5n)/|EF|`. Then the map from
  `f = (ρ(M_1), ρ(M_2), σ_{·,1}, …, σ_{·,n}) ∈ EF^{2n+8}` to the mask part of
  `(G_1, G_2, s_0, …, s_n)` is a bijection onto the space of mask transcripts that pass the sum
  checks (dimension `2 + 6 + 2n`).
  *Proof.* The map is block lower-triangular in the round order, so it is enough to check each
  diagonal block.
  * **Round 0.** Write `E_j(X) = eq_D(τ_{j,0}, X) = ¼(1 + τ³X + τ²X² + τX³)`. Since
    `Σ_{z∈D} E_j(z) R_j(z) = R_j(τ_{j,0})`, the image lies in
    `{(G_1, G_2, C): deg C ≤ 6, Σ_D C = λ_1 G_1 + λ_2 G_2}`, which has dimension 8, the same as
    the domain. For injectivity, suppose `R_j(τ_{j,0}) = 0` and
    `λ_1 E_1 R_1 = −λ_2 E_2 R_2`. Take `τ_{1,0} ≠ 0` (so `deg E_1 = 3`), `gcd(E_1, E_2) = 1`
    and `λ ≠ 0`. Then `E_1 | R_2`, so `R_2 = c·E_1` and `R_1 = −(λ_2/λ_1) c E_2`. Then
    `R_2(τ_{2,0}) = c·eq_D(τ_{1,0}, τ_{2,0}) = 0` forces `c = 0` unless
    `eq_D(τ_{1,0}, τ_{2,0}) = 0`. The bad events are: `τ_{1,0} = 0` (1); the resultant
    `Res_X(E_1, E_2) = 0`, a degree-≤ 9 polynomial in `τ_{2,0}` that is non-zero at
    `τ_{2,0} = 0` (9); `eq_D(τ_{1,0}, τ_{2,0}) = 0` (3); `λ = 0` (1).
  * **Round `i ≥ 1`.** The fresh part is `(σ_1, σ_2) ↦ Σ_j λ_j E_{j,i} σ_j q_j` with
    `q_j = eq1(τ_{j,i}, X)(X − τ_{j,i})` and `q_j(0) + q_j(1) = 0`. The target
    `{deg ≤ 2, p(0) + p(1) = 0}` has dimension 2, and the map is bijective iff `q_1`, `q_2` are
    not proportional and `λ_j E_{j,i} ≠ 0`. `q_j` has roots `τ_{j,i}` and
    `ρ(τ_{j,i}) = (τ−1)/(2τ−1)`, so proportionality needs `τ_{2,i} ∈ {τ_{1,i}, ρ(τ_{1,i})}`
    or `2τ = 1` (3). `E_{j,i} = 0` needs `u_l = ρ(τ_{j,l})` or `eq_D(τ_{j,0}, u_0) = 0`
    (2 per round, plus 6 once).

  Total: `14 + 5n + 6 + 1 ≤ (21 + 5n)/|EF|`. □
  With D1, `(stacking transcript mask part, symbols of M_1, M_2)` is uniform, independent of
  the trace and `M_s`. So the whole stacking transcript is uniform over the transcripts that
  pass the sum checks. That set is the trace part plus the mask space, and it depends only on
  the public claim.
* **Lemma W (WHIR pad).** The pads have coefficients `μ^{j_0}(1, μ, …, μ^{11})` (stacking
  coefficient 0). They are an `F`-basis of `EF` unless `μ` lies in a proper subfield or is 0, a
  set of size `< 2p^6`. Otherwise `Π = Σ_b μ^{j_0+b} P_b` is uniform in `EF^N` and independent of
  every non-pad column. So `g = Π + Σ_{non-pad} γ_j col_j` is uniform and independent of
  everything else in the view except:
  * `B = ĝ(u) − νS`. This is an identity, since `S = Σ_j c_j q̂_j(u)` and the pads have
    `c_j = 0`.
  * The pad symbols, which are determined by `g(α)` and the non-pad symbols.

  The bad event has probability `≤ 2p^6/p^12 = 2^-184.4`. □

## 7. Public inputs: the trace heights (review #4)

The FINAL proof sends each AIR's `log_height` and tight height in the clear. V_d does not compare
them with the setup: `check_height_caps` only checks `maxLog`, and the FINAL vk has none. The
three chunks have different heights, and also different setups (program lengths
142,654 / 143,132 / 144,468). The simulator of §6 receives the heights as input.

* If the heights are a function of the setup, the packet is ZK for `(claim, setup)`. That is
  plausible: the NV program is straight-line, with no branch opcodes in `nv/isa.rs`, so every
  AIR's row count is fixed by the program. But tight heights are "last non-zero row", which
  could in principle depend on data.
* If they are not, they leak information about L_n (for example multiproof sizes, which depend
  on query positions), and the simulator cannot produce them.

**Fix (obligation H, an owner decision because it changes the setup file):**
1. Record the FINAL heights in the setup.
2. Have V_d require equality.
3. Have the FINAL prover pad its tight heights to the recorded values. Zero rows are free: the
   virtual zero tail.

This also removes the layout-amplification surface, review #3 (about 3× verifier work for
adversarial heights).

Until the fix lands, `zero_knowledge_established=false`. The simulator argument itself is
complete.
